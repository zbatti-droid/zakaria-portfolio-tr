Multilingual interfaces need more than translated strings. Direction, spacing, navigation order, forms and content hierarchy all need to remain clear when the layout changes from LTR to RTL.

In Dar Sidi Bibi and Bella Beauté, I keep the language choice visible, use direction-aware layout rules and test the same flows in both languages on small screens.
