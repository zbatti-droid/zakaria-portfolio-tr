# Zakaria Batti — Full-Stack Developer Portfolio

Personal portfolio showcasing selected web applications, technical skills, education, experience, writing, and contact links. Built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

Requirements: Node.js 20 or newer and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Useful commands

```bash
npm run lint
npm run build
npm run start
```

## Portfolio content

- `config/projects.ts` — project cards, direct project pages, live URLs, and technology stacks.
- `config/experience.ts` — work and project experience.
- `config/education.ts` — education history and institution links.
- `config/skills.ts` — skills displayed on the home and skills pages.
- `config/socials.ts` and `config/site.ts` — public profile and contact URLs.
- `public/` — portrait, CV, favicon, and project previews.

The contact form and optional analytics require the environment variables documented in `.env.copy`. Keep private credentials out of source control.
