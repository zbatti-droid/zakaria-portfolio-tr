# Portfolio overview

This repository contains Zakaria Batti's personal developer portfolio.

## Main pages

- `/` — introduction, work experience, education, skills, featured projects, contributions, notes, and contact links.
- `/projects` — project catalogue.
- `/projects/[projectId]` — a dedicated detail page for each configured project, including screenshots, technologies, description, and live/source links where available.
- `/experience` and `/experience/[expId]` — work and project experience.
- `/skills` — technology overview.
- `/blogs` and `/blogs/[slug]` — technical notes.
- `/contact` — contact form and direct contact options.
- `/resume` — CV download.
